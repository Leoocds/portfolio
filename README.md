# Portfólio · Leonardo de Lima Pedroso

Site pessoal feito com Next.js 16, React 19, TypeScript e Tailwind CSS 4, exportado como site estático.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # gera o site estático em out/
```

- Projetos: `src/data/projects.ts` (textos, stack, links e imagens)
- Prints: `public/projects/<projeto>/` (WebP, 1440×900 no desktop e 390×844 @3x no mobile)

Deploy: importe o repositório na Vercel; não precisa de configuração extra.
